# متجر نوفا ستور الإلكتروني مع لوحة تحكم ذكية (NovaStore)

مشروع متجر إلكتروني احترافي متكامل مبني باستخدام **React (Vite)**، **Tailwind CSS**، و **Framer Motion**، مع دعم كامل للغة العربية (RTL) ولوحة تحكم إدارية محمية (Admin Dashboard) لإدارة وإضافة المنتجات فورياً مع مزامنة الـ API.

---

## 🌟 الميزات الرئيسية

1. **واجهة المتجر الإلكتروني (Storefront):**
   - **Hero Section متطور**: بانر تفاعلي بأنيميشن جذاب وبطاقات عائمة وإحصائيات مباشرة.
   - **منتجات مباشرة من API**: جلب تلقائي لبيانات المنتجات والأقسام والتقييمات.
   - **بحث وتصفية ذكية (Live Search & Categories)**: بحث فوري مع تصنيف بالكبسولات وفرز حسب الأسعار والتقييمات.
   - **بطاقات المنتجات التفاعلية (Product Cards)**: تأثيرات تكبير (Zoom) ناعمة، شارات الخصومات، والتقييمات.
   - **نافذة التفاصيل السريعة (Quick View Modal)**: استعراض صور المنتج واختيار الكميات والإضافة المباشرة.
   - **سلة مشتريات تفاعلية (Cart Drawer)**: منزلقة من الجانب، مع إمكانية تعديل الكميات وتطبيق كوبون خصم (`NOVA20`).
   - **قائمة المفضلة (Wishlist Drawer)**: حفظ المنتجات المفضلة ونقلها للسلة بنقرة واحدة.
   - **نافذة إتمام الطلب (Checkout Modal)**: نموذج دفع متكامل مع تأثير الاحتفال (Confetti) ورقم تتبع للطلب.

2. **لوحة التحكم والمصادقة (Admin Dashboard & Authentication):**
   - **حماية المسارات (Protected Routes)**: مسار `/admin` محمي بالكامل، ولا يمكن لأي زائر إضافة أو تعديل منتجات إلا بعد تسجيل الدخول.
   - **صفحة تسجيل دخول أنيقة (Admin Login)**: مع خيار التعبئة التلقائية السريعة للحساب التجريبي.
   - **بيانات الدخول التجريبية**:
     - **البريد الإلكتروني:** `admin@store.com`
     - **كلمة المرور:** `admin123`
   - **إحصائيات ومؤشرات أداء (KPIs)**: إجمالي المنتجات، القيمة المالية للمخزون، تقييم المتجر، وتنبيهات نواقص المخزون.
   - **إدارة المنتجات (Add / Edit / Delete)**:
     - نافذة منبثقة لإضافة أو تعديل أي منتج.
     - معاينة مباشرة للصورة (Live Preview) مع نماذج صور جاهزة للاختيار السريع.
     - حفظ ومزامنة فورية (Persistence) في المتجر ولوحة التحكم.

3. **حركات وتأثيرات بصرية (Animations & UI):**
   - حركات سلسة باستخدام **Framer Motion** عند التمرير وفتح النوافذ والقوائم.
   - تصميم زجاجي عصري **Dark Glassmorphism** مع تدرجات لونية جذابة.
   - إشعارات تفاعلية أنيقة (Toast Notifications).

---

## 🚀 تشغيل المشروع محلياً

```bash
# تثبيت الحزم (إذا لزم الأمر)
npm install

# تشغيل خادم التطوير
npm run dev
```

سيفتح المشروع تلقائياً على الرابط: `http://localhost:3000`
